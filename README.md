# 📚 Student Task Manager

## 📌 Overview
Student Task Manager is a responsive web application developed using HTML, CSS, and JavaScript. It helps users manage daily tasks efficiently with a simple and modern interface.

## 🚀 Features
- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Filter (All, Pending, Completed)
- Progress Bar
- Dark Mode
- Task Counter
- Local Storage
- Responsive Design

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage
